
# Contexto de desarrollo

## Proyecto
JSON to CSV Converter - Ingeniería de Software II - TP11.

## Uso de inteligencia artificial
Se utilizó ChatGPT como herramienta de apoyo durante el desarrollo.

### Actividades asistidas
- Interpretación de los requisitos del trabajo práctico.
- Generación y revisión del conversor JSON a CSV.
- Elaboración de pruebas automatizadas con Pytest.
- Configuración de herramientas de calidad y seguridad.
- Preparación de GitHub Actions.
- Redacción de documentación técnica.

### Ejemplos de instrucciones utilizadas
- Implementar un conversor JSON a CSV con parámetros -i, -o y -d.
- Agregar soporte para entrada y salida estándar.
- Crear pruebas unitarias para alcanzar una cobertura mínima del 85%.
- Configurar Ruff, Black, MyPy, Pyright y Bandit.
- Preparar un workflow de GitHub Actions para verificar la calidad del proyecto.

## Validación humana
Las funcionalidades y pruebas se ejecutaron localmente y sus resultados fueron revisados durante el desarrollo.

## Resultados
- 13 pruebas automatizadas aprobadas.
- Cobertura del 88,33%.
- Ruff, Black, MyPy, Pyright y Bandit sin problemas reportados.
- Workflow de GitHub Actions preparado, pendiente de verificación remota.
