# Installation

## Stable release

To install JSON to CSV Converter, run this command in your terminal:

```sh
uv add json2csv
```

Or if you prefer to use `pip`:

```sh
pip install json2csv
```

## From source

The source files for JSON to CSV Converter can be downloaded from the [Github repo](https://github.com/matibaissetto/json2csv).

You can either clone the public repository:

```sh
git clone https://github.com/matibaissetto/json2csv
```

Or download the [tarball](https://github.com/matibaissetto/json2csv/tarball/main):

```sh
curl -OJL https://github.com/matibaissetto/json2csv/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd json2csv
uv sync
```
